Note on helper functions:
Helper functions prototypes must be above other function definitions
Helper functions if simple enough can be defined in full at in-place of the prototype
Helper function definition must be declared under the other function definitions
Make sure they have the static

No custom heap
Too messy, c-strings must be defined on either stack or statically defined. Must be careful of scope

No bools
Functions should instead…
Return 1, 0 for boolean like functions e.g. is_foo(Input) 1 -> truthy, 0 -> falsey
Return 0, or some value < 0 for “error” prone functions e.g. set_value(Input)
Return pointer or null for “error” prone functions e.g. get_cstring()

Errnos are to only be set but either system calls, OR custom replacement for library function that included them previously e.g. execpve()
